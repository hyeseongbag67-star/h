# Anatomia 3D — 인체 해부학 아틀라스

프레임워크나 빌드 도구 없이 **단일 `index.html` 파일**만으로 완성된 인터랙티브 3D 인체 해부학 학습 웹 애플리케이션입니다. (순수 HTML / CSS / Vanilla JS + CDN 방식 Three.js 및 Google Fonts)

## 주요 기능

- **3D 인체 및 16개 기관 시각화**: 반투명 X-Ray 외피, 피부(외피계), 골격 기준선, 전신 혈관(동맥·정맥) 및 주요 내부 장기·감각기관(뇌, 눈, 귀, 코, 갑상선, 기관·기관지, 폐, 심장, 간·담낭, 위, 비장, 이자, 신장·부신, 소장·대장) 3D 모델 제공
- **터치/클릭 해부학 해설**: 각 기관 선택 시 한글 명칭, 영문·라틴어 의학용어, 주요 생리적 기능, 평균 제원, 핵심 의학용어 해설 제공
- **계통별 필터 및 분해 보기**: 8개 계통 필터링 및 슬라이더를 통한 3D 분해 보기(Exploded View) 지원
- **카메라 제어**: 360도 회전, 확대/축소, 부위별 카메라 프리셋(`전신`, `두경부`, `흉부`, `복부`) 및 선택 장기 초점 이동

## 실행 방법

### 1. 로컬에서 바로 실행 (더블 클릭)
`index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge, Safari, Firefox 등)에서 바로 열면 즉시 실행됩니다. 별도의 서버나 `npm`, 빌드 과정이 필요하지 않습니다.

### 2. GitHub & Vercel 즉시 배포
1. `index.html` 파일을 GitHub 저장소 루트에 업로드합니다. (`package.json`, `build`, `dist` 불필요)
2. Vercel에서 해당 GitHub 저장소를 Import합니다.
3. Framework Preset: **Other** (Build Command / Output Directory 설정 없음) 그대로 **Deploy** 하면 즉시 정적 사이트로 배포됩니다.
